# War in the World: Future Front

A mobile-first browser prototype for **War in the World: Future Front**.

## Play
Open `index.html` locally or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`). After deployment, use the Pages URL shown in Settings → Pages.

## Controls
- Mobile: on-screen joystick to move, drag the scene to rotate the camera, FIRE to test the weapon, SPRINT to move faster.
- Keyboard: WASD or arrow keys to move; hold Shift to sprint.
- The 3D engine is loaded from jsDelivr, so an internet connection is required.

## Current prototype
- Lightweight third-person sci-fi outpost.
- Responsive mobile HUD and virtual joystick.
- Camera look, sprint, basic movement, and firing feedback.
- Low-cost rendering settings intended as a starting point for mobile performance.
