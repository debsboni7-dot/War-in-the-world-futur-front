# Boîte de dépôt des assets

Dépose ici les fichiers d'assets encore non classés, en conservant si possible les fichiers qui vont ensemble dans la même archive ZIP.

Formats possibles : GLB, GLTF, OBJ, FBX, PNG, JPG, WebP, audio, archives ZIP et autres fichiers de ressources.

## Important
- Ce dossier est une zone d'arrivée temporaire : les fichiers seront identifiés puis déplacés vers `assets/models/`, `assets/textures/`, `assets/vfx/`, `assets/audio/`, `assets/animations/`, `assets/ui/`, `assets/fonts/` ou `assets/data/` selon leur rôle.
- Garde les noms de fichiers d'origine si possible.
- Pour les modèles accompagnés de textures ou de matériaux, envoie ensemble tous les fichiers associés, idéalement dans un ZIP.
- Évite d'ajouter des clés API, mots de passe ou autres secrets.

Une fois les fichiers téléversés, indique-moi ici que le dépôt est prêt afin que je puisse examiner ce qui est accessible et organiser les ressources.
