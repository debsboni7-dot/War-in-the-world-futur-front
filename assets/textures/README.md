# Textures and Materials

Put texture maps and material resources here.

Suggested subfolders: `characters/`, `weapons/`, `environment/`, `vehicles/`, `ui/`.

Use descriptive names and keep related maps together (base color/albedo, normal, roughness, metallic, ambient occlusion). Prefer WebP/JPEG for color maps and PNG for maps that need lossless data or transparency. Keep mobile texture sizes reasonable; reserve 2K/4K for assets that genuinely need them.
