# 3D Models

Put game models here, preferably in `.glb` format for web delivery.

Suggested subfolders:
- `characters/` — player, allies, enemies
- `weapons/` — guns, melee weapons, equipment
- `vehicles/` — cars, aircraft, boats
- `environment/` — buildings, props, rocks, vegetation
- `animals/` — wildlife and creatures

Keep model files optimized for mobile. Include a note with license/source and scale when adding an asset.
